# 课程开篇、模块过渡与总结类结构模板

这份结构用于选路，不是固定目录。先确定页面处在课程开篇、模块过渡、阶段总结还是整课总结，再选一条路径。

## 使用前填写

- 页面位置：`[课程开篇 / 模块过渡 / 模块总结 / 课程总结]`
- 目标受众当前状态：`[...]`
- 页面结束后要做的事：`[...]`
- 可验证的理解或行动：`[...]`
- 不在本页展开的知识：`[...]`

## 路径 A：课程开篇

1. 用具体处境说明课程面向谁，避免宣传性意义宣告。
2. 展示一个学习完成后的可观察结果或能力边界。
3. 说明课程主线、模块关系与核心路线，不逐章复述目录。
4. 列出真实前置、工具和学习方式；给出缺失前置的补救入口。
5. 说明学习成果怎样验收，以及课程明确不解决什么。
6. 给出进入第一模块的动作。

## 路径 B：模块过渡

1. 用一个短任务或结论唤回上一模块形成的能力。
2. 指出当前能力遇到的新限制。
3. 解释下一模块将补上哪部分能力，以及前文哪些知识会继续使用。
4. 给出进入下一章前的自检和补救路径。

## 路径 C：阶段总结

1. 围绕两到四个知识关系重组本模块，不按目录缩写。
2. 用判断、解释或小操作检查是否真正掌握。
3. 根据错误表现指向具体复习位置。
4. 说明下一阶段会怎样复用这些知识。

## 路径 D：课程总结

1. 回到课程学习成果，逐项说明已经形成的能力及其证据。
2. 把分散知识组合成一张工作流程、决策路径或能力地图。
3. 区分需要长期练习的部分和课程未覆盖的部分。
4. 提供几个有明确目的的后续方向，不给无边界资源清单。
5. 留下可执行的复习或迁移任务。

## 可选模块

学习路线图、术语索引入口、学习记录表、分层路径、阶段作品展示、后续课程选择标准。没有实际用途时全部省略。

## 交付前检查

- 删除课程宣传、欢迎套话和鼓励性金句后，页面是否仍有教学价值？
- 学习者能否说清自己现在在哪里、接下来做什么、怎样判断完成？
- 是否泄露内部材料、生成过程、评价分数或待审核状态？
