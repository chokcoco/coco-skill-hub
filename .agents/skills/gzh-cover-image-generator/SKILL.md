# 公众号封面图

为文章制作可以直接发布的公众号封面，而不是把文章内容缩略成一张信息图。封面的第一目标是让读者在信息流中停下来，第二目标才是解释主题。

## 适用范围

- 需要内嵌标题的公众号首图、文章头图或专题横幅。
- 需要在 2.35:1 横版画幅中建立强烈的标题层级和情绪张力。

不用于正文技术插图、产品 UI、品牌 Logo 或需要精确数据表达的图表。

## 交付要求

- 默认成品尺寸为 `1800 x 766`，比例严格为 `2.35:1`。
- 标题必须直接嵌入图片；用户给出的标题必须逐字保留，包括数字、中英文、引号和标点。
- 标题是主视觉，画面元素只服务于标题与文章的核心冲突。
- 生成候选图时，默认给出 3 个明显不同的创意方向；用户指定数量时以其要求为准。
- 成品保存到当前项目，使用可辨识且带版本号的文件名；不得覆盖已有候选图。

## 强制视觉语言

默认风格为“新潮工业反叛风”。除非用户明确要求改风格，以下全部要求必须保留。

### 设计风格

- **黑底强对比美学**：纯黑背景配以白色和荧光黄色元素，形成极强视觉冲击力。
- **地下文化气质**：类似独立音乐海报或前卫艺术展的反主流美学。
- **工业印刷风格**：模拟工业标识和手册的粗犷实用主义。
- **后现代解构主义**：打破传统设计规则，强调不规则性与碎片化。
- **都市青年反叛感**：通过设计表达对传统职场文化的质疑和调侃。
- **数字朋克气息**：融合数字时代的视觉元素与朋克文化的反抗精神。
- **实验性排版探索**：把排版本身作为设计表达的主要手段。

### 文字排版风格

- **巨型中文标题**：超大号汉字形成强烈的视觉重心。
- **轮廓线英文**：英文采用线条勾勒的空心字体，增强现代感。
- **多向阅读结构**：文字横向、纵向、分散排列，打破常规阅读习惯。
- **拆分重组文本**：将词语拆解并重新组合排版。
- **重复性文本背景**：将口号反复呈现作为背景填充。
- **极端字号对比**：从超大到极小的文字尺寸变化，创造丰富层次。
- **悬浮式文字布局**：各文本块看似随意又有序地悬浮在画面中。

### 视觉元素风格

- **线条鱼图形符号**：简笔画风格的鱼作为核心视觉标识和概念象征。
- **星号装饰点缀**：使用 `*` 符号作为点缀元素，增添活力。
- **几何框架结构**：L 形、方块、椭圆等简单几何形状构建画面架构。
- **日期数字化处理**：`07.05-08.20` 等数字信息以现代技术感的方式呈现。
- **荧光高亮区域**：使用荧光黄突出关键内容，如重点数字或项目名。
- **重复元素韵律**：通过元素重复创造视觉节奏和连续性。

## 工作流

1. 提炼文章的一个主冲突：反常增长、利益变化、风险警示、权力反转或旧规则失效。不要把所有论点堆到封面上。
2. 阅读 [封面风格与参考](references/cover-style.md)，并查看其中列出的参考资产。参考的是视觉原则，不是要求复刻某一张图。
3. 首选 **GPT Image 2.5** 生成；不可用时使用 **GPT Image 2**。Prompt 必须明确：2.35:1 横构图、标题逐字文本、标题的颜色和层级、仅少量支持性隐喻，以及禁止添加额外可读文本。
4. 检查标题是否完整、清晰、未被裁切；构图是否在缩略图中仍有明确的视觉焦点。标题错误或可读性不足时，针对文字问题单独重试。
5. 将合格图片裁切或整理为 `1800 x 766`，保存到项目目录；不在文章中自动替换封面，除非用户明确指定。

## 关键约束

- 标题要大、短行、对比强。优先将数字、项目名或反常结论放到最大字号。
- 视觉表达可以夸张，但不得暗示未经证实的事实、攻击真实人物或使用受限品牌标识。
- 正文配图和封面必须风格分工：正文讲清机制，封面制造阅读张力。
- 不要使用常见的蓝紫渐变、通用 3D 机房、浮空图标堆砌或伪 UI；它们会稀释公众号封面的编辑感。

## 工具

优先使用 **GPT Image 2.5** 生成位图封面；模型不可用或调用不支持时降级为 **GPT Image 2**。需要生成中文标题时，在 Prompt 中重复完整标题，并要求“exact, complete, crisp, readable Chinese title”；成图后必须人工检查文字。
