# Comparison Template / 对比模板

## Purpose / 用途

用来帮助读者在少数明确维度上比较方案，并看清适用条件。它不是功能清单。

Help readers compare options across a few explicit dimensions and see where each applies. It is not a feature dump.

## Layout / 布局

- 列是方案，行是 3-6 个决策维度；先给维度，再填结论。
- 每格只放一个明确判断，使用短句、等级符号或简洁图标。
- 最后一行可写“适合什么情况”，但不得把推荐伪装成客观事实。
- 优劣颜色在全图内一致，并说明符号含义。

- Use options as columns and 3-6 decision dimensions as rows; define the dimensions before filling conclusions.
- Put one clear judgment in each cell, using short copy, rating marks, or concise icons.
- A final “best fit” row is allowed, but do not disguise a recommendation as objective fact.
- Keep favorable/unfavorable colors consistent and explain the symbols.

## Prompt Skeleton / 提示词骨架

```text
Create a technical comparison matrix titled “[title]”.
Columns: [option A], [option B], [option C].
Rows: [decision dimension 1] through [decision dimension 5].
For every cell, use one short, evidence-grounded assessment. Add a final “best fit” row with stated conditions.
Use clear grid alignment, restrained watercolor fills, and a legend for check, caution, and limitation symbols.
```

## Review / 验收

- 每行是否是可比较的同一维度？
- 每个判断是否带条件，避免绝对化？
- 是否能在十秒内看出差异和适用场景？

- Is every row one comparable dimension?
- Does each judgment include its condition instead of overstating?
- Can readers see differences and fit in ten seconds?
