# Conceptual Explainer Template / 概念解释模板

## Purpose / 用途

用来让抽象概念变得可感知，同时保留技术边界。比喻只能辅助理解，不能替代真实机制。

Make an abstract idea graspable while keeping its technical boundary intact. Metaphor may support understanding but cannot replace the real mechanism.

## Layout / 布局

- 用一个中心隐喻或可视对象承载概念，但周围必须有技术卡片把它落回输入、转换和结果。
- 隐喻区不超过画面的一半，避免做成海报。
- 明确写出“这个比喻说明什么”和“它不代表什么”。
- 若概念可拆成两层，顶部给直觉，底部给机制。

- Use one central metaphor or visual object, but surround it with technical cards that ground it in input, transformation, and outcome.
- Keep the metaphor under half the frame so the image does not turn into a poster.
- State what the metaphor explains and what it does not represent.
- When the concept has two levels, put intuition on top and mechanism below.

## Prompt Skeleton / 提示词骨架

```text
Create a conceptual technical illustration titled “[title]”.
Use “[metaphor]” only to explain “[specific intuition]”.
Pair it with three technical cards: input “[input]”, transformation “[mechanism]”, outcome “[output]”.
Add a boundary note: “This illustration explains [scope]; it does not imply [non-equivalence].”
Use the shared watercolor-and-ink infographic style, with the technical cards more prominent than decorative scenery.
```

## Review / 验收

- 隐喻是否帮助理解一个具体问题？
- 图中是否有足够技术锚点，避免被误读为真实拓扑？
- 限制说明是否可见且自然？

- Does the metaphor clarify a specific question?
- Are there enough technical anchors to prevent readers from treating it as literal topology?
- Is the limitation visible and natural?
