# Overview Template / 全景概览模板

## Purpose / 用途

用来回答“这个领域由哪些部分构成，它们围绕什么核心协同”。中心是概念核心，外围是 4-6 个稳定类别。

Use this to answer: “What makes up this landscape, and what do the parts coordinate around?” Place the core concept in the center with 4-6 stable categories around it.

## Layout / 布局

- 中心放一句核心概念和一个简单图标。
- 外围卡片按读者的理解顺序顺时针或从左到右排列。
- 只画核心与外围的主要关系；外围之间的关系另放在简短回路或旁注里。
- 用轻量图例说明颜色对应的层级或角色。

- Put one core concept and a simple icon in the center.
- Arrange surrounding cards clockwise or left-to-right by the reader's mental order.
- Draw only major core-to-periphery relationships; put peer relationships in a small loop or annotation.
- Use a light legend for colors that encode layer or role.

## Prompt Skeleton / 提示词骨架

```text
Create a technical ecosystem overview titled “[title]”.
Center: “[core concept]”.
Surround it with [4-6] numbered cards: [category and one short explanation for each].
Show [relationship type] between the center and each card. Add one small callout for “[important boundary]”.
Use the shared watercolor-and-ink visual language. Make the radial or hub-and-spoke structure immediately visible. Keep labels concise and readable.
```

## Review / 验收

- 不看正文时，读者能否分辨核心、类别与主要关系？
- 外围卡片是否属于同一抽象层级？
- 连线是否少到足以一眼读懂？

- Without body text, can a reader distinguish the core, categories, and main relationships?
- Do surrounding cards share one abstraction level?
- Are there few enough connections to read at a glance?
